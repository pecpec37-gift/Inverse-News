# 朝5分インバースネットNews

インバースネット株式会社（BTOパソコン「FRONTIER」、中古PC・スマホの買取販売、法人向けレンタル、修理・キッティング、リユース・リサイクル、データ消去）の商機につながるニュースを、毎朝5分で読める日本語ダイジェストにまとめる個人用のスマホ向けアプリです。

**インバースネット株式会社の公式サイトではありません。** 公開されている報道や発表だけをもとに作成しています。

- 公開URL: https://pecpec37-gift.github.io/Inverse-News/
- 毎朝 6:30ごろ（日本時間）、Claude の定期タスクが新しい号を `news` ブランチに追加します。

## データの置き場所

- `data/index.json` … 号の一覧（新しい順、最大30号）
- `data/editions/YYYY-MM-DD.json` … 各号の本文

`items[].cat` は `inv` `demand` `reuse` `erase` `sales` `ai` のいずれかです。`items[].rel` は商機のヒント、`items[].lines` は関係する事業（BTO・中古販売・買取・レンタル・キッティング・修理・リサイクル・データ消去・サーバー）です。
